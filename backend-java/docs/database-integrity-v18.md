# V18 全系统数据库完整性说明

> 数据库：`wust_dormitory`  
> 正式迁移最高版本：`V18`  
> 结构唯一事实来源：`backend-java/server/src/main/resources/db/migration/`

## 1. 本次审查发现

### 1.1 学生欢迎语被测试数据清理删除

V7 已创建并初始化 `STUDENT_WELCOME_MESSAGE`，V11 已将其规范为中英文 JSON 对象。问题不在架构迁移，而在旧版千人数据清理：`system_setting` 未进入保留清单，导入数据后欢迎语被删除。

### 1.2 配置表可能存在孤儿管理员引用

旧清理逻辑关闭外键检查并删除普通管理员，但保留：

- `system_setting`；
- `matching_weight_scheme`；
- `batch_rule_template`。

其可空创建人或修改人字段可能指向已经删除的管理员。

### 1.3 派生配额告警可能过期

`service_quota_alert` 由当前业务数据规模派生。测试数据重置后保留旧告警会造成平台显示错误。

### 1.4 正式空库缺少批次创建参考数据

正式 V1～V17 未保证存在：

- 已发布个人偏好问卷；
- 问卷单选题选项；
- 已启用匹配权重方案。

开发测试迁移会插入这些数据，但正式应用和 Navicat 架构不应依赖测试迁移。

## 2. 正式迁移职责

### V17

```text
V17__restore_required_system_configuration.sql
```

负责：

- 幂等恢复中英文欢迎语；
- 清理配置表孤儿管理员引用；
- 缺少时恢复 `SYSTEM_DEFAULT` 批次规则模板。

### V18

```text
V18__seed_required_business_reference_data.sql
```

仅在缺少可用参考配置时初始化：

- `SYSTEM-PREFERENCE-V1` 已发布个人偏好问卷；
- 20 个最终版个人偏好题目；
- 所有单选题选项；
- `SYSTEM_DEFAULT` 启用匹配权重方案。

已有管理员自定义的已发布问卷或启用匹配方案不会被覆盖。

## 3. 必需数据不变量

| 对象 | 要求 |
|---|---|
| 系统管理员 | `SYSTEM_ADMIN` 恰好一个 |
| 学生欢迎语 | 恰好一条，包含非空 `zh-CN` 与 `en-US` |
| 默认套餐 | `FULL_CURRENT` 存在 |
| 当前服务订阅 | `PRIMARY_SERVICE` 存在且当前修订恰好一条 |
| 默认批次规则 | `SYSTEM_DEFAULT` 修订 1 可用 |
| 已发布问卷 | 至少一份，包含启用题目 |
| 单选题选项 | 已发布问卷的每个启用单选题至少一个启用选项 |
| 匹配权重方案 | 至少一个启用方案，权重与冲突规则均为 JSON 对象 |
| 功能与配额目录 | 核心第一阶段能力、选床模式权限和核心资源配额存在 |

## 4. 测试数据重置不变量

千人数据清理必须保留：

- 系统设置；
- 唯一系统管理员；
- 问卷、问卷题目与选项；
- 匹配方案；
- 批次规则模板；
- 功能、配额、套餐和订阅目录。

删除普通管理员前，应将保留配置中的可空创建人或修改人设为 `NULL`。

重置后必须清空：

```text
service_quota_alert
```

## 5. Navicat 完整性检查

执行：

```text
backend-java/docs/sql/navicat/04_数据库完整性检查/
00_修复并检查数据库完整性.sql
```

脚本验证：

- Flyway V18；
- 关键表、字段、索引、外键；
- 欢迎语、问卷、选项、匹配方案、规则模板；
- 功能、配额、套餐和订阅；
- 孤儿引用；
- 活动批次锁；
- 重复有效在住与重复现实床位占用。

成功状态：

```text
DB_INTEGRITY_OK
```

## 6. 应用层防御

`SystemSettingService` 在读取或修改欢迎语前，通过唯一键冲突安全的原子写入确保配置存在。该机制用于兼容历史开发库，正式数据库仍必须执行 V17、V18 并通过完整性检查。
