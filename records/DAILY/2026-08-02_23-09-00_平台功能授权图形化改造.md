# 2026-08-02 平台功能授权图形化改造

## 1. 改造目标

将系统管理员原有的“手工输入功能代码、选择 GRANT 或 REVOKE、查看原始 JSON”页面，改造为适合日常运营使用的全图形化细粒度授权界面。

用户确认采用：

```text
单项滑动开关立即生效
+ 批量编辑模式
```

## 2. 后端实现

新增接口：

```text
GET  /api/v1/platform/features/entitlements
PUT  /api/v1/platform/features/{featureCode}/state
POST /api/v1/platform/features/batch-state
```

新增目标状态：

```text
ENABLED
DISABLED
INHERIT
```

后端负责：

- 计算套餐默认状态；
- 计算当前有效覆盖；
- 返回最终有效授权状态；
- 根据目标状态自动推导 GRANT 或 REVOKE；
- 恢复套餐默认时终止当前有效覆盖；
- 避免重复提交相同状态产生重复有效覆盖；
- 禁止授权 `enabled_in_program=0` 的未来功能；
- 批量变更使用一个数据库事务；
- 任一项目失败时整体回滚；
- 单项和批量操作写入平台审计。

## 3. 前端实现

`PlatformFeaturesView.vue` 已改造为：

- 功能名称和功能代码搜索；
- 第一、第二、第三阶段筛选；
- 管理端、学生端、共享范围筛选；
- 开启、关闭、单独覆盖、套餐默认和未来功能筛选；
- 按阶段和业务模块分组；
- 每个功能使用滑动开关；
- 单项切换弹出原因确认框；
- 请求中显示开关加载状态；
- 失败后保留原状态并显示错误；
- 套餐默认、单独增补、单独移除、风险等级和尚未实现标签；
- 批量编辑模式；
- 分组全部开启、全部关闭和恢复套餐默认；
- 固定底部批量保存栏；
- 开启、关闭、恢复默认数量预览；
- 统一填写批量变更原因；
- 取消批量编辑时恢复进入批量模式前的状态。

未来功能只在打开“显示未来功能”后出现，卡片和开关均为禁用状态。
