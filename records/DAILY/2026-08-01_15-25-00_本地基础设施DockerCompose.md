> 范围：A 方案——仅容器化 MySQL 与 Redis

## 1. 用户要求

- 继续开发宿舍选择系统；
- 参考“城安智序”的 Docker 目录、统一环境变量和启动脚本；
- 先实施 A 方案；
- Docker 只承载本地基础设施，后端和前端在宿主机运行。

## 2. 关键决策

- 使用根目录 `.env` 作为 Docker Compose 与 Spring Boot 的统一配置入口；
- 使用 MySQL 8.4 和 Redis 7.4 Alpine 官方镜像标签；
- MySQL 数据写入 `data/mysql/`；
- Redis 开启追加文件持久化并写入 `data/redis/`；
- MySQL 使用独立业务账号，后端禁止使用 root；
- Redis 必须启用密码认证；
- Compose 只包含 `mysql`、`redis` 两个服务；
- 通过 Bash 脚本完成配置校验、启停、健康等待和日志输出；
- `restart` 使用强制重建容器，确保 `.env` 中的 Redis 密码等环境变量变化能够生效；
- Spring Boot 通过 `spring.config.import` 导入根目录 `.env`；
- 后端增加 Spring Data Redis Starter。
