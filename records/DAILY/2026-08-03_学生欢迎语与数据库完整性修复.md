# 2026-08-03 学生欢迎语与全系统数据库完整性修复报告

## 1. 问题现象

管理员访问学生欢迎语配置时返回：

```text
SYSTEM_SETTING_NOT_FOUND
学生欢迎语配置不存在
```

## 2. 欢迎语问题根因

V7 已创建 `system_setting` 并插入 `STUDENT_WELCOME_MESSAGE`，V11 已将其规范为中英文 JSON 对象。问题来自旧版千人测试数据清理：

1. `clear_1000_test_data()` 删除未进入保留清单的普通表；
2. `system_setting` 未进入保留清单；
3. 导入干净或真实千人数据后，欢迎语单例被删除；
4. 管理员服务要求记录存在，因此返回 404。

## 3. 全系统审查发现的其他问题

### 3.1 配置创建人孤儿引用

测试数据清理关闭外键检查并删除普通管理员，但保留系统设置、匹配方案和批次规则模板。可空的创建人或修改人字段可能保留已删除管理员编号。

### 3.2 过期配额告警

`service_quota_alert` 由当前业务数据规模派生，测试数据重置后继续保留会造成错误告警。

### 3.3 正式空库缺少批次创建参考配置

正式 V1～V17 没有保证存在：

- 已发布个人偏好问卷；
- 单选题选项；
- 已启用匹配权重方案。

开发测试迁移包含这些数据，但正式架构和 Navicat 建库不能依赖测试迁移。真实千人数据脚本也明确依赖这些参考配置。

## 4. 修复内容

### 4.1 Flyway V17：系统配置恢复

```text
V17__restore_required_system_configuration.sql
```

负责：

- 幂等恢复中英文欢迎语；
- 清理配置表无效管理员引用；
- 幂等恢复缺失的系统默认批次规则模板。

### 4.2 Flyway V18：正式业务参考数据

```text
V18__seed_required_business_reference_data.sql
```

仅在缺少可用配置时初始化：

- `SYSTEM-PREFERENCE-V1` 已发布个人偏好问卷；
- 20 个最终版个人偏好题目；
- 全部单选题选项；
- `SYSTEM_DEFAULT` 启用匹配权重方案。

已有管理员自定义的已发布问卷或启用匹配方案不会被覆盖。

### 4.3 千人测试数据

修改公共基础、场景入口和生成器：

- 保留 `system_setting`；
- 删除普通管理员前清理可空配置引用；
- 欢迎语缺失时自动恢复；
- 清空历史 `service_quota_alert`；
- 干净数据断言欢迎语恰好一条；
- 独立 Navicat 数据文件内联同样的保护逻辑。

### 4.4 Navicat

数据库架构升级到 V18：

```text

18_V18__seed_required_business_reference_data.sql
```

Flyway 基线升级为 V18。

两套数据目录均增加：


新增并升级数据库完整性检查：

### 4.5 应用层

`SystemSettingService` 在读取或修改欢迎语前，使用唯一键冲突安全的原子写入确保单例配置存在，兼容尚未执行 V17 的历史开发库。
