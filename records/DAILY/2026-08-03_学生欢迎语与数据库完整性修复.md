# 2026-08-03 学生欢迎语与数据库完整性修复报告

## 1. 问题现象

管理员访问学生欢迎语配置时返回：

```text
SYSTEM_SETTING_NOT_FOUND
学生欢迎语配置不存在
```

## 2. 根因

正式数据库架构不存在遗漏：

- V7 创建 `system_setting`；
- V7 插入 `STUDENT_WELCOME_MESSAGE`；
- V11 将欢迎语规范为中英文 JSON 对象；
- Navicat 中的 V7、V11 与正式 Flyway 迁移一致。

问题来自千人测试数据清理脚本：

1. `clear_1000_test_data()` 会删除未进入保留清单的普通表；
2. `system_setting` 未进入保留清单；
3. 因此导入干净或真实千人数据后，欢迎语单例被删除；
4. 管理员服务要求该记录必须存在，所以返回 404。

## 3. 额外完整性问题

审查同时发现：

- 测试数据清理关闭外键检查并删除普通管理员；
- 匹配方案、批次规则模板和系统设置被保留；
- 可空的创建人或修改人字段可能保留已被删除的管理员编号；
- `service_quota_alert` 属于业务数据派生状态，重置数据后继续保留会显示过期告警；
- 原有脚本只验证千人数据数量，没有验证运行必需系统配置和跨表孤儿引用。

## 4. 修复内容

### 4.1 Flyway V17

新增：

```text
backend-java/server/src/main/resources/db/migration/
V17__restore_required_system_configuration.sql
```

作用：

- 幂等恢复中英文学生欢迎语；
- 清理配置表无效管理员引用；
- 幂等恢复缺失的系统默认批次规则模板。

### 4.2 千人测试数据

修改公共基础和生成器：

- 保留 `system_setting`；
- 删除普通管理员前清空配置表中的可空引用；
- 欢迎语缺失时自动恢复；
- 清空历史 `service_quota_alert`；
- 干净数据断言欢迎语恰好一条。

### 4.3 Navicat

数据库架构升级到 V17：

```text
backend-java/docs/sql/navicat/01_数据库架构/
17_V17__restore_required_system_configuration.sql
```

Flyway 基线升级为 V17。

两套数据目录增加：

```text
02_恢复必需系统配置.sql
```

新增数据库完整性检查：

```text
backend-java/docs/sql/navicat/04_数据库完整性检查/
00_修复并检查数据库完整性.sql
```

### 4.4 应用层

`SystemSettingService` 在读取或修改欢迎语前，使用唯一键冲突安全的原子语句确保单例配置存在。

## 5. 完整性检查范围

检查脚本覆盖：

- V1～V17关键表；
- 关键字段、唯一索引和外键；
- Flyway V17状态；
- 唯一系统管理员；
- 中英文学生欢迎语；
- 核心功能和配额目录；
- 默认套餐、当前订阅和默认批次规则；
- 学生、专业、床位、布局、在住与配置孤儿引用；
- 活动批次锁状态；
- 重复有效在住和重复现实床位占用。

成功输出：

```text
DB_INTEGRITY_OK
```
