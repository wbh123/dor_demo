# 2026-08-03 Navicat 统一数据库脚本整理

## 1. 需求

- 所有数据库脚本统一使用 `wust_dormitory`；
- 数据库架构导入前删除旧数据库、创建新数据库并切换数据库；
- 两套测试数据导入前清空学校业务数据；
- 数据库架构、1000人干净数据、1000人真实业务数据统一存放；
- 支持 Navicat，不依赖 MySQL 客户端 `SOURCE`；
- 保留自动生成和过期检查能力。

## 3. 数据库架构套件

按文件名顺序执行：

```text
00_删除并创建数据库.sql
01_V1__create_phase1_schema.sql
...
16_V16__add_residency_student_category_and_transfer_support.sql
99_写入Flyway基线.sql
```

第一份脚本执行：

```sql
DROP DATABASE IF EXISTS `wust_dormitory`;
CREATE DATABASE `wust_dormitory`
  CHARACTER SET utf8mb4
  COLLATE utf8mb4_0900_ai_ci;
USE `wust_dormitory`;
```

最后一份脚本创建 Flyway V16 基线。以后新增 V17 后，Spring Boot 可以继续从 V17 执行迁移，不会重复执行 V1—V16。

## 4. 测试数据套件

两套数据均先执行：

```text
00_使用统一数据库.sql
```

随后执行对应主数据脚本。

主数据脚本包含：

```sql
CREATE PROCEDURE clear_1000_test_data()
```

- 套餐与订阅；
- 问卷版本；

输出：

