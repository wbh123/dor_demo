# 高校宿舍智能选择平台

一个面向高校宿舍选择与住宿分配场景的通用平台，计划公开学生账号激活、个人偏好、组队选寝、房间与床位选择、统一分配、住宿调整、国际化和审计等能力。

> 当前仓库是公开发布目标仓库。正式源码将通过**无私有历史的清理快照**导入；原开发仓库继续保持私有，不会直接转换为公开仓库。

## 公开版原则

- 不包含特定高校名称、校区和对外品牌信息；
- 不包含内部需求、系统设计、开发阶段记录、甲方材料和部署文档；
- 不包含真实学生数据、生产配置、日志、数据库备份或访问凭据；
- Java 包名、环境变量前缀、数据库名和容器名等技术性历史标识暂时保留；
- 公开仓库使用单次初始提交，不继承私有仓库 Git 历史。

## 技术栈

- 前端：Vue 3、TypeScript、Three.js
- 接口：OpenAPI 3
- 后端：Java、Spring Boot
- 数据：MySQL、Redis、Flyway
- 实时状态：服务器发送事件
