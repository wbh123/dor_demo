# 高校宿舍智能选择平台（公开脱敏开发仓库）

本仓库用于脱敏后的功能开发、自动化测试和 GitHub Actions 持续集成验证。完整业务资料、数据库结构和项目文档保存在非公开环境中，本仓库不作为完整项目事实源或最终交付仓库。

## 仓库用途

允许在本仓库中保存：

- 已去除学校、校区、人员、真实数据和内部业务标识的前后端代码；
- 单元测试、接口测试、前端测试和构建测试；
- GitHub Actions 工作流；
- 仅包含占位值的配置示例；
- 不泄露内部信息的最小化 `README.md`、`AGENTS.md`、许可证和安全说明。

功能在本仓库完成并通过 GitHub Actions 后，验证通过的代码会被选择性迁移到私有完整仓库，并在私有仓库中补充数据库迁移、完整配置、项目文档和最终验证记录。

## 严格禁止内容

本仓库不得提交或通过提交信息、拉取请求、日志、截图、附件泄露以下内容：

### 数据库结构

- Flyway、Liquibase 等正式数据库迁移；
- 建表、改表、索引、约束和触发器脚本；
- `schema.sql`、数据库备份和结构快照；
- 数据字典、实体关系图、表关系和字段说明；
- 能够反推出真实业务表结构的完整持久化模型、测试夹具或初始化数据；
- 真实数据库连接信息和生产参数。

数据库相关功能只能使用不反映真实结构的接口替身、模拟仓储、内存对象或最小匿名测试模型进行验证。

### 内部项目文档

- 需求分析、系统设计、开发阶段计划和验收材料；
- `docs/`、`records/`、会议纪要、甲方材料和内部沟通记录；
- 部署拓扑、生产运维、安全处置和未公开功能路线图；
- 私有仓库完整目录、内部文件清单或业务资料。

### 敏感信息

- 真实学生、教师、管理员或其他人员数据；
- 学校、学院、校区和内部品牌标识；
- 密钥、令牌、密码、证书、私钥和真实环境变量；
- 生产日志、导出文件、内部域名、服务器地址和数据库地址。

对内容是否适合公开存在疑问时，默认不得提交。

## 开发流程

```text
创建公开仓库主题分支
→ 实现脱敏功能与自动化测试
→ 运行 GitHub Actions
→ 记录通过的提交 SHA 和持续集成结果
→ 将相关代码选择性迁移到私有完整仓库
→ 在私有仓库补充数据库、配置、文档和最终验证
```

公开仓库持续集成通过只表示本仓库中的脱敏代码通过验证，不表示完整项目功能已经完成。

## 提交前检查

```text
[ ] 不含数据库迁移、建表脚本、结构快照和数据字典
[ ] 不含 docs、records、需求、设计和验收材料
[ ] 不含学校、校区、人员和内部品牌标识
[ ] 不含真实数据、生产配置、日志、密钥和内部地址
[ ] 测试数据完全虚构且不能反推真实数据库结构
[ ] GitHub Actions 日志不会输出敏感信息
```

详细的智能体和开发约束见 [`AGENTS.md`](AGENTS.md)。

## 技术栈

- 前端：Vue 3、TypeScript、Three.js
- 接口：OpenAPI 3
- 后端：Java、Spring Boot
- 数据访问：通过抽象接口或脱敏测试替身验证
- 实时状态：服务器发送事件
