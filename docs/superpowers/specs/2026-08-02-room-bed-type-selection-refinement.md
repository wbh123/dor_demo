# 床位类型管理与学生选寝交互调整

## 管理端

- 房间普通属性编辑不再允许直接修改房型。
- 床位类型、床位坐标、朝向和房型同步统一在可视化布局编辑器中完成。
- 空床位可以切换为上床下桌、上下铺上铺或上下铺下铺。
- 已存在有效床位分配的非空床位禁止修改类型，后端返回冲突错误。
- 保存布局时根据物理床位总数同步四人间、五人间、六人间或其他房型，并同步容量。
- 可拖动床位控件采用 190×90 像素矩形，移动端采用 114×54 像素矩形；编辑器整体宽度和高度适当收缩。

## 学生端

- 个人偏好卡片标题区与内容区间距缩短。
- 偏好表格和右侧画像区域等高撑满，用户画像和标签完整展示。
- 右侧两个主要按钮固定在底部，使用统一内边距和固定高度。
- 单选题使用唯一选项标识维护选中状态，避免多个选项拥有相同匹配数值时错误选中最后一项。
- 选床页面将“当前选择”和“临时保留”固定并排展示。
- 未临时保留时不显示倒计时，释放和确认按钮保持置灰；保留成功后才显示倒计时并启用操作。
