## 3. 已完成子项目

### 3.1 逐房间床位布局配置

Flyway V5新增`room_bed_layout`。管理员可以拖拽床位、调整坐标和朝向，学生三维场景读取同一数据库布局。

固定规则：

- 房间容量等于物理床位总数，维护或停用床位不减少容量；
- 真正的上下铺必须由同一床架下的一张`BUNK_UPPER`和一张`BUNK_LOWER`组成；
- 其他历史床架不会被错误合并成上下铺；
- 坐标和朝向受后端与数据库校验；
- 保存必须填写原因并校验`room.version`；
- 学生三维视图采用开放视角，不显示遮挡床位的两侧长墙。

### 3.2 匹配运营与推荐解释

Flyway V6为匹配权重方案增加不可变修订。批次引用精确方案修订，后续新修订不会改变历史批次评分。

固定规则：

- 权重与冲突规则使用中文运营表单维护；
- 修改必须填写原因并写审计；
- 学生候选房间按批次引用的修订确定性排序；
- 学生端只展示公开推荐理由和冲突提示，不公开其他学生完整个人偏好。

### 3.3 学生体验、国际化与复杂组队异常

Flyway V7新增首次欢迎状态和系统设置，V8扩展高影响个人偏好，V9增加国籍、手机号和学生系统通知，V11规范化历史欢迎语JSON。

已经实现：

- 五人队伍成员卡片；
- 待确认邀请不计入组队人数；
- 开始组队选寝时取消未确认邀请；
- 队长移除成员；
- 成员主动退出；
- 进入个人选寝前自动退出或解散队伍；
- 中文和英文切换，外国学生默认使用英文；
- 中文和英文首次欢迎语；
- 学生国籍展示和本人手机号维护；
- 组队变更系统通知。

加固规则：

- 队伍仍持有Redis临时床位占用时，移除成员、退出队伍和切换个人选寝返回`TEAM_HOLD_ACTIVE`；
- 必须先释放队伍临时占用，避免床位一直锁到超时；
- 文档对象模型翻译器区分自身翻译写入与Vue响应式更新，不再用旧文本覆盖姓名、人数和接口消息；
- V11将JSON标量、`null`、数组或缺少语言键的欢迎语规范化为中英文对象。

### 3.4 完整批次配置复制

接口：

```text
POST /api/v1/admin/batches/{batchId}/copy
```

复制内容：

- 问卷版本；
- 匹配方案精确修订；
- 批次规则模板精确修订；
- 临时占用、续期、组队、随机推荐和未选处理规则快照；
- 楼栋、房间和床位开放范围。

不复制学生资格、活动学生锁、队伍、邀请、Redis占用、正式分配和分配运行。新批次固定为`DRAFT`，异常资源会使事务整体回滚。

### 3.5 批次规则模板

Flyway V10新增`batch_rule_template`，管理员可以创建模板首个修订和基于已有修订创建新修订。

固定规则：

- 模板修订不可覆盖；
- 新启用模板允许组队时人数范围为2至5，不允许组队时固定为1人；
- 全库最多一个默认模板，默认模板必须启用；
- 新建批次显式选择精确模板修订；旧客户端未提交模板时使用默认模板；
- 批次保存`rule_template_id`，同时保留全部执行规则快照；
- 运行中的选寝只读取批次快照，不动态读取模板；
- 批次复制同时复制模板引用和规则快照；
- 模板创建、修订、默认切换和批次创建写入审计；
- V10把历史规则快照映射为停用历史模板，不允许用于新批次。

管理端新增：

```text
/admin/rule-templates
```

页面支持模板列表、默认标识、创建模板、创建新修订和移动端表单。批次创建页面展示模板规则摘要并提交精确模板主键。
