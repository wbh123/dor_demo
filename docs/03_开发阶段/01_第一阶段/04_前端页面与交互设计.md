# 第一阶段前端页面与交互设计

> 文档编号：DOC-PHASE1-UI-001  
> 状态：第一阶段开发基线  
> 日期：2026-08-01

## 1. 技术边界

前端使用：

```text
Vue 3
TypeScript 5.9
Vite
Vue Router
Pinia
Axios
openapi-typescript
```

固定规则：

- 开发和生产构建前自动读取后端主 OpenAPI 生成 TypeScript 类型；
- 所有业务请求经过统一 Axios 客户端；
- Bearer 令牌保存在本地存储，用户信息由 `/api/v1/auth/me` 恢复；
- 路由守卫区分管理员和学生；
- 服务器发送事件通过带 Authorization 请求头的 Fetch 流读取；
- 前端状态不是最终事实，关键动作完成后重新读取服务端结果。

## 2. 公共页面

### 2.1 登录与学生激活

登录支持：

- 管理员用户名与密码；
- 学生学号与激活后密码。

学生首次使用：

```text
输入12位学号
→ 输入与导入数据一致的姓名
→ 设置密码
→ 激活成功
→ 使用学号登录
```

错误信息直接使用服务端契约中的稳定错误响应。

### 2.2 应用布局

桌面端使用侧边栏，移动端转为顶部导航。管理员和学生显示不同入口。

## 3. 学生端页面

### 3.1 选寝首页

展示：

- 学号、姓名、性别和专业；
- 有资格参与的批次；
- 批次状态、临时占用时间、组队和随机推荐能力；
- 问卷、房间、队伍和结果入口。

### 3.2 生活习惯问卷

- 动态读取问卷题目；
- 支持时间、整数、布尔和选择题；
- 必填项未完成时禁止提交；
- 提交后服务端重新计算标准化特征；
- 明确提示问卷不用于人格评价。

### 3.3 候选房间

- 按匹配分排序；
- 展示楼栋、房间、房型、楼层、剩余床位；
- 展示主要匹配项和注意项；
- 支持按楼栋或房间号搜索；
- 支持学生随机推荐，但推荐不会直接形成最终分配；
- 队伍模式只展示能够容纳完整队伍的房间。

### 3.4 房间和床位

床位状态：

```text
AVAILABLE       可选
HELD            被其他操作临时占用
HELD_BY_ME      当前用户占用
ASSIGNED        已正式分配
DISABLED        禁用或维护
```

个人模式：

```text
选择床位
→ Redis临时占用
→ 显示倒计时
→ 主动释放或最终确认
```

队伍模式：

```text
选择与成员数相同的同房间床位
→ Lua脚本整体占用
→ 显示统一倒计时
→ 整体释放或整体确认
```

页面建立房间级服务器发送事件连接。收到床位事件后重新拉取权威快照，页面离开时关闭连接。

### 3.5 我的队伍

- 创建队伍；
- 按学号邀请；
- 接受或拒绝邀请；
- 队长锁定队伍；
- 锁定后进入整体选寝；
- 展示队伍编码、状态和成员数量。

### 3.6 最终结果

只展示数据库中的当前有效分配，包括：

- 楼栋；
- 房间；
- 床位；
- 床位类型；
- 分配方式；
- 分配时间。

临时占用和随机推荐不显示为最终结果。

## 4. 管理端页面

### 4.1 工作台

展示：

- 学生数量；
- 房间数量；
- 启用床位数量；
- 当前有效分配数量；
- 批次进度；
- 最近审计操作。

### 4.2 专业与学生

专业：

- 新增；
- 启用和禁用；
- 编号与名称唯一。

学生：

- 学号或姓名搜索；
- 新增学生；
- 只维护学号、姓名、性别和专业；
- 新学生账号默认为待激活。

### 4.3 宿舍资源

- 楼栋统计；
- 房间列表和筛选；
- 房型、容量、固定性别、运行状态和备注维护；
- 房间容量必须等于启用床位数量；
- 修改必须填写原因并记录审计。

### 4.4 选寝批次

- 创建草稿批次；
- 准备学生资格和宿舍范围；
- 按状态机发布、开放、暂停、关闭和结束；
- 统一分配预演；
- 正式执行；
- 结果导出。

### 4.5 分配与调整

- 按批次查询当前有效分配；
- 支持按学号、姓名、楼栋或房间搜索；
- 每名学生返回同批次、同性别、未占用且在范围内的候选床位；
- 人工调整必须选择候选床位并填写原因；
- 成功后刷新列表；
- 调整前后数据、原因和操作人进入历史及审计。

## 5. 响应式设计

- 大屏：固定侧边栏和多列卡片；
- 中屏：两列布局；
- 小屏：单列布局和横向导航；
- 表格允许水平滚动；
- 床位卡片自动换行；
- 关键提交按钮在移动端保持可见。

## 6. 前端构建

```bash
cd frontend
npm install
npm run dev
npm run typecheck
npm run build
```

`npm run dev` 和 `npm run build` 都会先生成：

```text
frontend/src/api/schema.d.ts
```

该文件为构建产物，不应手工修改。
