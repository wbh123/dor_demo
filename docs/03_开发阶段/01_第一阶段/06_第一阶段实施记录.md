# 第一阶段实施记录

> 日期：2026-08-01  
> 状态：已完成并冻结  
> 分支：`feature/phase1-minimal-student-major`

## 1. 需求边界

### 1.1 学生与专业

学生业务信息只保留：

```text
学号
姓名
性别
专业编号
```

已建立独立`major`表，学生通过`major_id`关联；账号通过`app_user.student_id`关联；批次住宿资格保存在`batch_student_eligibility`。班级、年级、学院层级、校区快照和永久住宿资格不进入学生表。

### 1.2 宿舍

- 当前男生五人间、女生四人间；
- 男生五人间为3个上床下桌和1组上下铺；
- 女生四人间为4个上床下桌；
- 房间固定为男寝或女寝；
- 管理员按批次配置楼栋、房间和床位范围；
- 数据模型支持后续男女各自四人间、五人间混合。

### 1.3 工程边界

- Spring Boot单体后端；
- Vue 3前端；
- MySQL保存最终事实；
- Redis保存令牌和临时占用；
- 房间级服务器发送事件推送；
- 生活习惯匹配使用可解释确定性算法；
- 所有接口采用OpenAPI契约驱动模式。

## 3. OpenAPI驱动实施

契约按照领域拆分并由`openapi-interface.yaml`统一汇总：

```text
auth/
admin/
student/
realtime/
common-response/
```

生成接口：

```text
AuthApi
AdminApi
StudentApi
RealtimeApi
```

对应Controller仅实现生成接口，不手写接口路径和请求数据传输对象。前端通过`openapi-typescript`从同一契约生成类型。
