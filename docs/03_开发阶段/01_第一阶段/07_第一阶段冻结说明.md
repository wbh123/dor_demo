## 1. 冻结范围

本次冻结包含以下稳定边界：

- OpenAPI驱动的认证、管理端、学生端和实时接口；
- 专业、学生、宿舍资源和选寝批次；
- 问卷、特征、匹配和随机推荐；
- 个人与组队选寝；
- Redis临时占用和令牌；
- MySQL最终分配事务；
- 房间级服务器发送事件；
- 管理员统一分配、查询、导出、调整和审计；
- Vue学生端与管理员端第一阶段页面；
- Flyway V1、V2、V3及固化数据库结构。

## 2. 冻结架构

```text
Vue 3 + TypeScript
    ↓ REST / 服务器发送事件
OpenAPI 3契约
    ↓ 自动生成Java API、数据传输对象和TypeScript类型
Spring Boot 4单体应用
    ├── MySQL 8.4：最终业务事实
    └── Redis 7.4：令牌、临时占用和可重建状态
```

不得绕过的规则：

1. 新接口先修改OpenAPI；
2. Controller只实现生成接口；
3. 已执行Flyway迁移不得修改；
4. Redis不得作为最终分配事实；
5. 分配确认、统一分配和人工调整必须事务化；
6. 关键操作必须写入历史或审计；
7. 前后端构建和完整运行流程必须进入持续集成。
