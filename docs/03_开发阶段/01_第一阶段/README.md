## 3. 当前房型规则

当前学校需求为：

```text
男生：五人间，3个上床下桌 + 1组上下铺
女生：四人间，4个上床下桌
```

数据库不把该组合写死。后续可以出现男生、女生分别具有四人间和五人间混合的情况，但始终禁止男女混住，每个房间必须设置明确性别属性。

管理员在批次中可以精确配置：

- 可选楼栋；
- 可选房间；
- 可选床位；
- 男生和女生分别可选的宿舍范围。

## 5. 数据库演进规则

开发期间：

```text
新增Flyway版本迁移
→ 空库迁移测试
→ 已有数据库升级测试
→ 更新文档
```

第一阶段全部功能开发并验收完成后：

```bash
python scripts/db/build_frozen_baseline.py
```

生成独立数据库结构SQL。开发测试数据不进入固化脚本。
