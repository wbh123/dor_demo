## 3. 第二阶段已完成能力

### 逐房间床位布局配置

Flyway V5新增`room_bed_layout`，管理员现在可以为每个房间独立设置床位平面坐标与朝向：

- 宿舍资源页面提供布局入口；
- 支持俯视拖拽、0.25单位吸附、90度旋转和数值输入；
- 上下铺上下层作为同一床架整体设置位置与朝向；
- 保存必须提交全部床位、填写原因并通过房间版本校验；
- 修改前后布局写入审计；
- 学生Three.js场景读取同一数据库布局；
- 没有自定义记录的旧房间继续使用默认斜视纵向布局；
- WebGL不可用时仍可使用下拉框选床；
- 本地重建脚本自动识别最新正式Flyway版本。

第二阶段正式迁移：

```text
V5__add_room_bed_layout.sql
```
