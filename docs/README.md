## 3. 当前状态

```text
准备阶段：已完成
第一阶段：已完成并最终冻结
第二阶段：开发中
第三阶段：待评估
```

第一阶段已形成：

- OpenAPI驱动的认证、管理端、学生端和实时接口；
- 专业、学生、宿舍、批次、问卷与确定性匹配；
- 个人选寝与邀请式组队；
- Three.js三维选床、下拉框联动和移动端适配；
- Redis临时占用、MySQL最终确认和服务器发送事件；
- 统一分配、导出、人工调整与审计；
- Flyway V1至V4、固化结构和完整HTTP验收。

## 4. 第一阶段最终门禁

持续集成必须同时通过：

- Docker和环境变量配置测试；
- 数据库结构、测试数据、MySQL兼容性和固化文件漂移测试；
- OpenAPI引用、操作编号和Controller实现约束；
- Java 21 Maven全模块生成、单元测试和构建；
- Vue OpenAPI类型生成、TypeScript检查、Three.js和生产构建；
- MySQL、Redis、Flyway和Spring Boot真实启动；
- 管理员、学生、个人选寝、邀请式组队、确认、调整和审计的HTTP闭环。

## 5. 第二阶段方向

第二阶段：开发中。当前优先级：

1. 每个房间独立床位布局与上下铺位置配置；
2. 匹配权重、冲突解释和运营界面；
3. 批次复制、规则模板和复杂组队异常处理；
4. 导入质量、安全、统计、性能和Redis恢复；
5. 分配优化和公平性评估。

第二阶段不得回写V1至V4，不得绕过OpenAPI，不得削弱最终分配唯一约束和房间固定性别规则。

## 6. 本地测试数据

推荐使用：

```bash
bash scripts/dev/reset-local-environment.sh
```

该脚本只重建MySQL与Redis，通过Flyway执行正式结构，再由MySQL客户端导入开发数据，避免测试数据污染Flyway历史。
