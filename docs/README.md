## 3. 文档优先级

发生冲突时按以下顺序判断：

1. 用户最近一次明确指令；
2. 根目录和子目录 `AGENTS.md`；
3. 当前阶段目录中的设计、计划和验收文档；
4. OpenAPI、Flyway迁移和当前代码事实；
5. 总体需求和系统设计；
6. README；
7. `records/`历史记录。

已经执行的Flyway迁移属于不可回写的历史事实。数据库结构变化必须新增迁移并同步文档。

## 5. 阶段文档扩展规则

每个正式阶段至少包含：

- 阶段README；
- 详细开发计划；
- 数据库与数据口径设计；
- OpenAPI和错误码设计；
- 前端交互设计；
- 测试与验收设计；
- 实施记录；
- 阶段冻结说明。

第一阶段全部功能完成后，必须运行数据库固化工具，并冻结稳定的数据库约束、OpenAPI和核心业务规则。
