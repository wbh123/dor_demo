## 3. 文档优先级

发生冲突时按以下顺序判断：

1. 用户最近一次明确指令；
2. 根目录和子目录`AGENTS.md`；
3. 当前阶段设计、验收和冻结文档；
4. OpenAPI、Flyway迁移、自动化测试和当前代码事实；
5. 总体需求与系统设计；
6. README；
7. `records/`历史记录。

已执行的Flyway迁移属于不可回写的历史事实。后续数据库结构变化必须新增迁移，并重新生成固化结构快照。

## 5. 第一阶段验收门禁

持续集成必须同时通过：

- 基础设施配置测试；
- 数据库结构、测试数据、MySQL兼容性和固化文件漂移测试；
- OpenAPI引用、操作编号和Controller实现约束；
- Java 21 Maven全模块生成、单元测试和构建；
- Vue OpenAPI类型生成、TypeScript检查和生产构建；
- MySQL、Redis、Flyway和Spring Boot真实启动；
- 管理员与学生完整HTTP选寝、确认、调整和审计流程。

## 6. 后续阶段规则

第二阶段开始前，应基于第一阶段冻结边界新增计划，不得直接改写第一阶段已经执行的Flyway迁移，也不得绕过OpenAPI手写Controller接口。
