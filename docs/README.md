## 2. 数据库文档维护要求

`backend-java/docs/database-dictionary.md`是必须持续维护的正式文档。

- 每次新增Flyway版本或数据库字段时，必须同步更新数据字典；
- 已经执行的旧Flyway迁移禁止回写，只能新增更高版本；
- 每次结构变化后必须运行`python scripts/db/build_frozen_baseline.py`更新固化结构；
- 数据库重置和测试数据脚本必须与最新Flyway版本、字段和约束保持一致；
- 拉取请求涉及数据库变化时，数据字典和固化结构缺失应视为未完成。

## 5. 本地测试数据

推荐使用：

```bash
bash scripts/dev/reset-local-environment.sh
```

脚本会：

1. 清空项目本地MySQL和Redis持久化数据；
2. 执行正式目录中的全部Flyway版本；
3. 建立或保留测试管理员账号；
4. 导入20名待激活学生、8个房间、36个床位及管理功能样例；
5. 校验全部学生资格、国际学生、组队通知和分配失败样例；
6. 不把测试数据写入`flyway_schema_history`。
