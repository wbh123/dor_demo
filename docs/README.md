- 本地重建脚本自动识别最新正式迁移版本。

## 4. 本地测试数据

推荐使用：

```bash
bash scripts/dev/reset-local-environment.sh
```

脚本只重建MySQL与Redis，自动执行正式目录中的最新Flyway版本，再由MySQL客户端导入开发数据，避免测试数据污染Flyway历史。
